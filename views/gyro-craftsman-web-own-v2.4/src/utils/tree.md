# 工具函数目录结构说明

## 目录结构

```
.
├── auth.js                   # 认证相关工具
├── authDialog.js             # 认证弹窗工具
├── beautifierLoader.js       # 代码美化加载器
├── compressImg.js            # 图片压缩工具
├── directive.js              # 指令工具
├── emitter.js                # 事件发射器
├── file.js                   # 文件操作工具
├── formDesignerUtils.js      # 表单设计器工具
├── format.js                 # 格式化工具
├── get-page-title.js         # 页面标题获取
├── i18n.js                   # 国际化工具
├── i18ns.js                  # 国际化配置
├── index.js                  # 工具函数集合
├── numberFormat.js           # 数字格式化工具
├── preload.js                # 预加载工具
├── resourceUtil.js           # 资源工具
├── rgbaster.js               # 颜色提取工具
├── scroll-to.js              # 滚动工具
├── tips.js                   # 提示工具
├── uploadChunk.js            # 分片上传工具
├── uploadCloud.js            # 云上传工具
├── util.js                   # 通用工具
├── validate.js               # 验证工具
├── validators.js             # 验证器集合
└── watermark.util.js         # 水印工具
```

## 工具分类说明

### 数据处理类
- format.js: 数据格式化工具
- numberFormat.js: 数字格式化工具
- validate.js: 数据验证工具

### 文件处理类
- file.js: 文件操作工具
- compressImg.js: 图片压缩工具
- uploadChunk.js: 分片上传工具

### UI相关类
- scroll-to.js: 滚动定位工具
- watermark.util.js: 水印工具
- authDialog.js: 认证弹窗工具
